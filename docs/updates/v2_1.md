# LeTools-Learning 更新日志

**2026-11-12**

## Key Features

### 1. DAgger 人工介入与数据采集

- 新增 Quest3 人工接管、平滑回切和 Rosbag 录制，支持单臂、双臂及 5W 全身配置。[DAgger 说明](../../README_DAGGER.md)。

### 2. 统一异步推理与动作聚合

- 真机、仿真和离线评测统一异步推理流程，支持动作预取、按执行步对齐及多种 chunk 聚合方式。

### 3. RTC 训练与推理

- 为 OpenPI、GR00T N1.7 和 LingBot-VLA v2 增加 **guided / trained** RTC 支持[rtc 说明](../../kuavo_deploy/readme/rtc.md)。

### 4. 部署与控制优化

- 新增独立控制线程与线性插值，支持推理和动作下发分离，并保留限速与末端指令去重。

### 5. SG100 与离线评测改进

- SG100 数转、在线观测和离线评测统一关节弧度与标定二值化处理[sg100 说明](../../kuavo_deploy/readme/sg100.md)，新增从 Bag 生成部署 YAML 的工具。
- 修复离线评测的 H.265 连续解码与时间对齐，支持按 Bag 时间戳进行异步重放。
