# SG100 数据、模型与部署约定

SG100 原始状态和命令为左右各 11 维弧度。不同关节量程不同，包含负角度；使用 `sg100_joint_min/max` 逐关节限幅。驱动采用关节位置模式。

## 11 DOF：实际关节角度

数转、在线观测和离线评测保留实际弧度，不再统一除以 1.57；部署直接下发模型给出的弧度，再按逐关节范围限幅。

```yaml
# 数转
dataset:
  eef_type: sg100
  which_arm: both
  dex_dof_needed: 11
  dex_dof_offset: 0
  is_binary: false
```

```yaml
# 部署覆盖配置，其他项由 total 提供
env:
  eef_type: sg100
  which_arm: both
  sg100_dof_needed: 11
  sg100_dof_offset: 0
  is_binary: false
  is_binary_sg100_action: false
```

每侧动作布局为 `[arm7, eefN]`，双臂 11 DOF 为 36 维，单臂为 18 维。5W 下半身和底盘按既有布局追加。模型服务的末端维度必须与训练/部署一致。

旧的 `/1.57` 归一化 checkpoint 不能直接按新弧度语义部署，需要明确转换或重新训练。

## 1 DOF 二值开合

选择有实际开合行程的代表关节，按 `(q-open)/(close-open) > ratio` 判断闭合。分母保留符号，支持反向运动关节。

```yaml
dataset:
  eef_type: sg100
  which_arm: both
  dex_dof_needed: 1
  dex_dof_offset: [5, 5]
  is_binary: true
  sg100_binary_open: [0.0, 0.0]
  sg100_binary_close: [1.57, 1.57]
  sg100_binary_ratio: 0.1
```

上述数值是格式示例，应按设备标定填写。数转支持左右不同 offset 和每手/完整 22 维标定；部署当前使用左右相同的 `sg100_dof_offset`，左右不同代表关节的数据不能直接套用同一个部署 offset。

```yaml
env:
  eef_type: sg100
  sg100_dof_needed: 1
  sg100_dof_offset: 5
  is_binary: true
  is_binary_sg100_action: true
  sg100_binary_ratio: 0.1
  # sg100_open_pose / sg100_close_pose：左右各 11 维实际弧度
```

在线、离线和数转共享二值化实现。离线评测读取部署的 open/close/ratio，避免沿用数转模板中的另一套标定。1 DOF 动作以 0/1 表示开合，再按完整 open/close 姿态展开。二值数据的末端名称为 `left_grip/right_grip`。

1 DOF 非二值链路仍需按模型明确换算：当前数转保留代表关节角度，部署将单维动作视为 `[0,1]` 开合量。该模式需要显式的数据/模型转换，不能套用上述二值配置。

## 配置与验收

按设备匹配 DOF、代表关节、开合标定、ratio、逐关节限位和模型输出单位。通用数转默认仍使用 leju_claw，部署保留 beta 的通用设备配置；启用 SG100 时显式填写覆盖配置。

ROS 话题为 `/sg100_hand_state` 和 `/sg100_hand_command`。消息兼容层、驱动和 SDK 需与现场版本配套。静态检查和离线单元测试不能替代实际设备验收。

## 从 bag 生成部署覆盖配置

```bash
python tools/sg100_bag_to_yaml.py --bag /path/to/demo.bag \
  --sg100-dof 11 --sg100-binary false \
  --output configs/deploy/sg100_task.yaml --validate
```

工具从命令/状态提取初始、开合姿态和关节范围，缺少的数据沿用 total；可用 `--print-only` 检查结果。关节范围只扩展、不缩小已有标定。1 DOF 模型使用 `--sg100-dof 1 --sg100-dof-offset 5`，开合语义仍需与模型核对。

bag 无法证明模型是否使用二值动作，使用 `--sg100-binary` 显式指定。生成后检查字段来源、开合幅度、实际限位以及模型/相机配置；工具不会修改模型服务配置。
